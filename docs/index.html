为什么这四条

2013、2017、2021、2025 四轮牛市都同时具备：前一熊清完杠杆 → 联储从紧转松 → 减半供给窗口 → 一个以前没有的新买家（散户→ICO→机构→ETF）。没有一轮牛市是在加息周期里启动的。
